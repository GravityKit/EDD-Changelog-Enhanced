# Changelog

All notable changes to EDD Changelog Enhanced will be documented in this file.

## 1.3 - 2026-11-22

### Improved
- Collapsible `<details>` sections in a changelog, such as each GravityView Pro feature's notes, show as bordered sections that open and close.

## 1.2 - 2026-03-12

### Fixed
- Sitemap no longer includes changelog URLs for downloads without changelog content (e.g., All Access Pass bundles)
- Resolved static analysis warnings for DOMDocument property access and unused parameters

### Added
- Generator meta tag in changelog pages for source attribution

## 1.1

### Added
- Yoast SEO sitemap integration for changelog URLs
- Smart date detection using latest version date as `lastmod`
- Priority adjustment for changelog URLs in sitemap

### Changed
- Simplified caching system with plugin version integration

## 1.0

### Added
- Initial release
- Semantic HTML5 with proper heading hierarchy
- Microformats support
- SEO optimization with meta tags and structured data
- Social media integration with featured image support
- Iframe embedding support with security headers
- Mobile-responsive and print-friendly design
- Theme template overrides
- UTF-8 and emoji handling
- Intelligent caching with automatic invalidation
